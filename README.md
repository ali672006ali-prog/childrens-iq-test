# اختبار ذكاء الأطفال — د. إجلال محمد سرى

منصة رقمية إكلينيكية لتطبيق وتصحيح اختبار ذكاء الأطفال وحساب نسبة الذكاء، مع إصدار تقارير تشخيصية ثنائية اللغة مدعومة بالذكاء الاصطناعي.

إهداء كلية التربية النوعية إلى كلية الآداب بجامعة المنوفية.

## التقنيات

- React + TypeScript + Vite
- Firebase (Firestore)
- Gemini API لتوليد التقارير التشخيصية

## التشغيل محليًا

```bash
npm install
npm run dev
```

يلزم توفير مفتاح Gemini API في ملف البيئة (راجع `.env.example`).
